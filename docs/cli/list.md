# List Command

`burger-api list` (alias `ls`) shows the official hooks and plugins with a short description of each. Install one with `burger-api add <name>`.

```bash
burger-api list
```

The list comes from GitHub and is saved for a few hours. If GitHub is not reachable, the CLI shows the saved list and says so.
